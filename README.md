👨‍💻Eco-Analysis-Engine---App – Sustainability Rating System

👨‍💻Eco-Analysis-Engine

Is a desktop-based sustainability evaluation system that allows users to assess, compare, and rank products based on multiple sustainability metrics. The application provides a clean GUI to input product data, automatically calculate a Sustainability Index (SI), assign grades, and visualize comparisons.

This project is ideal as a student software engineering project, demonstrating skills in Java desktop development, data handling, analytics, and visualization.

🚀 Features

➕ Add New Products

Enter product name

Rate sustainability parameters on a 0–10 scale:

Material

Energy

Waste

Longevity

Social Impact



📊 Sustainability Index (SI)

Automatically calculates an average Sustainability Index

Assigns grades (e.g., B, B+, A) based on SI score


🗂 Product Database

Displays all products in a structured table

Shows:

Individual category scores

SI value

Final grade



🔍 Search & Manage

Search products by name

Delete selected products


📈 Visualization

Bar chart comparison of product sustainability scores

Highlights the best-performing product


📤 Export

Export all product data to CSV format for reporting and analysis


📌 Summary Insights

Average SI across all products

Total number of products

Best product based on SI



---

🖥️ Tech Stack

Language: Java

UI Framework: JavaFX / Swing (GUI-based)

Database: In-memory / Local storage

Charts: Java charting library

Export: CSV file generation



---

🧮 Sustainability Index Formula

SI = (Material + Energy + Waste + Longevity + Social) / 5

Grades are assigned based on SI score ranges (configurable in code).
